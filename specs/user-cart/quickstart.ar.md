# دليل البدء السريع: سلة التسوق للمستخدم

**الميزة**: user-cart  
**التاريخ**: 2024-10-29  
**الغرض**: دليل التحقق السريع لوظائف السلة

## المتطلبات الأساسية

1. **قاعدة البيانات**: تم تشغيل الترحيلات بنجاح
2. **المصادقة**: رمز JWT لمستخدم الاختبار
3. **بيانات الاختبار**: 
   - متجران معتمدان مع منتجات
   - منتجات مع خيارات وإضافات مكونة
   - حساب مستخدم اختبار

## سيناريوهات الاختبار السريع

### السيناريو 1: إضافة أول عنصر إلى السلة (المسار السعيد)

**الهدف**: إنشاء سلة وإضافة أول منتج

```bash
# الطلب
POST /api/user/cart/items
Authorization: Bearer {token}
Content-Type: application/json

{
  "product_id": 1,
  "quantity": 2,
  "option_values": [5, 8],
  "addons": [
    {"addon_id": 3, "quantity": 1}
  ]
}

# الاستجابة المتوقعة: 201 تم الإنشاء
{
  "success": true,
  "message": "تمت إضافة العنصر إلى السلة بنجاح",
  "data": {
    "cart": {
      "id": 1,
      "store": {
        "id": 1,
        "name": "المتجر أ",
        ...
      },
      "items": [
        {
          "id": 1,
          "product": {...},
          "quantity": 2,
          "selected_options": [...],
          "selected_addons": [...],
          "item_price": "25.99",
          "item_total": "51.98"
        }
      ],
      "subtotal": "51.98",
      "total": "51.98",
      "item_count": 1
    }
  }
}
```

**التحقق**:
- ✅ تم إنشاء السلة في قاعدة البيانات
- ✅ السلة لديها store_id صحيح
- ✅ تمت إضافة العنصر بالكمية الصحيحة
- ✅ تم حفظ الخيارات والإضافات
- ✅ تم حساب الأسعار بشكل صحيح

### السيناريو 2: إضافة عنصر من نفس المتجر

**الهدف**: إضافة منتج آخر من نفس المتجر

```bash
# الطلب
POST /api/user/cart/items
Authorization: Bearer {token}
Content-Type: application/json

{
  "product_id": 2,
  "quantity": 1,
  "option_values": [10],
  "addons": []
}

# الاستجابة المتوقعة: 201 تم الإنشاء
{
  "success": true,
  "message": "تمت إضافة العنصر إلى السلة بنجاح",
  "data": {
    "cart": {
      "id": 1,
      "store": {...},
      "items": [
        {...}, // العنصر الأول
        {
          "id": 2,
          "product": {...},
          "quantity": 1,
          ...
        }
      ],
      "subtotal": "72.97",
      "total": "72.97",
      "item_count": 2
    }
  }
}
```

**التحقق**:
- ✅ تمت إضافة العنصر إلى السلة الموجودة
- ✅ السلة لا تزال لديها نفس store_id
- ✅ تم تحديث إجمالي السلة
- ✅ زاد عدد العناصر

---

### السيناريو 3: اكتشاف تعارض المتجر

**الهدف**: تفعيل التعارض عند الإضافة من متجر مختلف

```bash
# الطلب
POST /api/user/cart/items
Authorization: Bearer {token}
Content-Type: application/json

{
  "product_id": 10, // منتج من المتجر ب
  "quantity": 1,
  "option_values": [],
  "addons": []
}

# الاستجابة المتوقعة: 409 تعارض
{
  "success": false,
  "message": "السلة تحتوي على عناصر من متجر مختلف. إضافة هذا العنصر سيمسح سلتك الحالية.",
  "data": {
    "current_store": {
      "id": 1,
      "name": "المتجر أ",
      ...
    },
    "new_store": {
      "id": 2,
      "name": "المتجر ب",
      ...
    },
    "requires_confirmation": true,
    "confirmation_endpoint": "/api/user/cart/replace"
  }
}
```

**التحقق**:
- ✅ تم إرجاع رمز الحالة 409
- ✅ تم توفير معلومات المتجر الحالي والجديد
- ✅ لم يتم تعديل السلة
- ✅ تم توفير نقطة نهاية التأكيد

---

### السيناريو 4: تأكيد استبدال السلة

**الهدف**: استبدال السلة بمنتج من متجر مختلف

```bash
# الطلب
POST /api/user/cart/replace
Authorization: Bearer {token}
Content-Type: application/json

{
  "product_id": 10,
  "quantity": 1,
  "option_values": [],
  "addons": []
}

# الاستجابة المتوقعة: 201 تم الإنشاء
{
  "success": true,
  "message": "تم استبدال السلة بنجاح",
  "data": {
    "cart": {
      "id": 2, // معرف سلة جديد
      "store": {
        "id": 2, // المتجر ب
        "name": "المتجر ب",
        ...
      },
      "items": [
        {
          "id": 3, // معرف عنصر جديد
          "product": {...}, // منتج من المتجر ب
          "quantity": 1,
          ...
        }
      ],
      "subtotal": "15.99",
      "total": "15.99",
      "item_count": 1
    }
  }
}
```

**التحقق**:
- ✅ تم حذف السلة القديمة من قاعدة البيانات
- ✅ تم إنشاء سلة جديدة مع store_id جديد
- ✅ تمت إضافة عنصر جديد
- ✅ يظهر سجل النشاط استبدال السلة

### السيناريو 5: تحديث كمية العنصر

**الهدف**: تغيير كمية عنصر موجود

```bash
# الطلب
PUT /api/user/cart/items/3

{
  "quantity": 5

# الاستجابة المتوقعة: 200 نجح
{
  "success": true,
  "message": "تم تحديث الكمية بنجاح",
  "data": {
    "cart": {
      "id": 2,
      "items": [
        {
          "id": 3,
          "quantity": 5, // محدث
          "item_price": "15.99",
          "item_total": "79.95", // معاد حسابه
          ...
        }
      ],
      "subtotal": "79.95",
      "total": "79.95",
      ...
    }
  }
}
```

**التحقق**:
- ✅ تم تحديث الكمية
- ✅ تم إعادة حساب إجمالي العنصر
- ✅ تم إعادة حساب إجمالي السلة
- ✅ يظهر سجل النشاط تغيير الكمية

### السيناريو 6: إزالة عنصر

**الهدف**: إزالة عنصر من السلة

```bash
# الطلب
DELETE /api/user/cart/items/3
Authorization: Bearer {token}

# الاستجابة المتوقعة: 204 لا يوجد محتوى
# (تمت إزالة آخر عنصر، تم حذف السلة)
```

**التحقق**:
- ✅ تم حذف العنصر من قاعدة البيانات
- ✅ تم حذف السلة (كان آخر عنصر)
- ✅ يظهر سجل النشاط إزالة العنصر وحذف السلة

---

### السيناريو 7: عرض السلة

**الهدف**: استرجاع السلة الحالية

```bash
# الطلب
GET /api/user/cart
Authorization: Bearer {token}

# الاستجابة المتوقعة: 200 نجح (إذا كانت السلة موجودة)
{
  "success": true,
  "message": "تم استرجاع السلة بنجاح",
  "data": {
    "cart": {
      "id": 1,
      "store": {...},
      "items": [...],
      "subtotal": "51.98",
      "total": "51.98",
      "item_count": 1
    }
  }
}

# أو 404 غير موجود (إذا لم تكن هناك سلة)
{
  "success": false,
  "message": "السلة غير موجودة"
}
```

**التحقق**:
- ✅ تم استرجاع السلة مع جميع العلاقات
- ✅ تم حساب الأسعار بشكل صحيح
- ✅ الأسماء/الأوصاف مترجمة
- ✅ 404 عندما لا توجد سلة

---

**التحقق**:
- ✅ تم حذف جميع العناصر
- ✅ تم حذف السلة
- ✅ يظهر سجل النشاط مسح السلة

```bash

  "product_id": 99999, // غير موجود
```

## التحقق من قاعدة البيانات

بعد كل سيناريو، تحقق من حالة قاعدة البيانات:

```sql
-- التحقق من وجود السلة
SELECT * FROM carts WHERE user_id = {test_user_id};

-- التحقق من عناصر السلة
SELECT * FROM cart_items WHERE cart_id = {cart_id};

-- التحقق من الخيارات المحددة
SELECT * FROM cart_item_options WHERE cart_item_id = {item_id};

-- التحقق من الإضافات المحددة
SELECT * FROM cart_item_addons WHERE cart_item_id = {item_id};

-- التحقق من سجلات النشاط
SELECT * FROM activity_log 
WHERE log_name = 'cart' 
ORDER BY created_at DESC 
LIMIT 10;
```

## استكشاف الأخطاء وإصلاحها

### المشكلة: خطأ 500 عند إضافة عنصر
**التحقق من**:
- تم تشغيل الترحيلات بنجاح
- المفاتيح الخارجية موجودة
- المنتج/الخيارات/الإضافات موجودة في قاعدة البيانات

### المشكلة: أسعار غير صحيحة
**التحقق من**:
- نوع سعر قيمة الخيار وقيمة السعر
- أسعار الإضافات
- منطق حساب السعر في النموذج

### المشكلة: لم يتم اكتشاف تعارض المتجر
**التحقق من**:
- store_id للسلة يطابق store_id للمنتج
- منطق التحقق في المتحكم

### المشكلة: استجابة بطيئة
**التحقق من**:
- تم تكوين التحميل المسبق
- الفهارس موجودة في قاعدة البيانات
- عدد الاستعلامات باستخدام debugbar
